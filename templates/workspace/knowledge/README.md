# 业务知识与操作资料

保存整理过、可导航、可持续复用的业务知识、架构参考和操作方法，可包含专题辅助脚本、Skill 与非敏感样例。模板不预置业务主题；使用者按实际需要授权建立，并在本页登记入口。

- rules：公共开发流程；knowledge：业务是什么、如何查询和操作。
- artifacts：用户保存的原始需求、截图、附件与交付产物，不强制绑定需求。
- briefs：本次需求方案与执行事实；不是公共知识库。
- tmp：用户定期清理的临时杂物；不自动清理。

只加载当前任务相关专题。历史案例不等于当前事实，操作前核验源码、配置与环境；知识资料不能扩大执行授权。不得写入凭据或把业务知识自动提交到公共模板。
